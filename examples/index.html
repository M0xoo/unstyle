unstyle

Elevate your workflow with AIDesign that a model would not have picked on its own.

An agent skill for Claude Code, Codex, Cursor and other agents. It grounds each design choice in the subject, checks it against the model’s defaults, and scans the code for the tells that make a page look generated.

Install

Any agent that reads skills:

npx skills add M0xoo/unstyle

Claude Code plugin:

/plugin marketplace add M0xoo/unstyle
/plugin install unstyle@unstyle

Scanner only, no agent needed:

npx @m0xoo/unstyle src/

Exit code 2 on any P0 or P1, so it can gate CI.

How it works

  1. Use the design system the project already has. Stop if the UI is already good.
  2. Name the subject, its world, and the thing that world made before software.
  3. Write a six-line direction: palette, type, skeleton, signature, motion, voice.
  4. Attack it. Every line must finish “because this product…”. Generic reasons fail.
  5. Build from tokens with real content.
  6. Scan, render, and run the silhouette, swap and squint tests.

Banning Inter and purple is not enough. Models just move to the next default: Space Grotesk, cream and terracotta, mono eyebrow labels, 01 / 02 / 03. The skill tracks those too.
